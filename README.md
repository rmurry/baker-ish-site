# Baker-ish React + Vite site

A responsive marketing site for Baker-ish, built around the provided brand image.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Customize before launch

- Replace `@bakerish` in `src/App.jsx` with the actual Instagram handle.
- The order form currently uses `mailto:hello@baker-ish.com`. Replace it with Formspree, Shopify, or another form/order backend when ready.
- Review the pickup/delivery and lead-time language so it matches Baker-ish's actual policies.
- Add real cake-pop photography to expand the gallery/product sections when available.

The provided Baker-ish brand image lives at `src/assets/baker-ish-logo.jpeg`.
